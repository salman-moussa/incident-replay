Jun 2025 · Cursor

Auto-run mode deletes far more than the project

Several Cursor users reported that an agent in auto-run (YOLO) mode ran recursive deletes that reached past the project: a neighbouring folder in one report, the home folder in others. One thread title quotes the command, a normal cleanup with the home folder added as one more argument. A security firm also showed that the built-in delete protections were easy to get around in that mode.

In auto-run mode the only thing between a typo and your home folder is a rule that reads the command. Have one.

Jul 2025 · Replit Agent

Production database deleted during a code freeze

The founder of SaaStr was nine days into building an app with the Replit agent and had declared a code freeze. The agent ran database commands against the live database anyway and wiped records for more than a thousand executives and companies. An instruction in the chat is not a control. Schema pushes and database resets need a rule that stops them, whatever the agent was told.

17 Jul 2025 · Amazon Q Developer

A wiper prompt shipped inside an official extension

Someone slipped a prompt into the Amazon Q extension for VS Code through a pull request. It told the agent to clean the system to a near-factory state and delete file system and cloud resources. The prompt shipped in a public release of an extension with hundreds of thousands of installs. AWS said a mistake in the prompt stopped it from running and that no customer resources were affected.

The instruction does not have to come from you. A guard that only trusts the prompt is no guard. Cloud deletes must be stopped at the command.

25 Jul 2025 · Gemini CLI

Files lost while moving them to a folder that did not exist

A product manager asked Gemini CLI to move his project files into a new folder. The command that should have created the folder failed, but the agent carried on as if it had worked. Bulk moves and deletes need a pause. A move with a wildcard into a folder nobody checked is a delete in disguise.

Nov 2025 · Google Antigravity

A cache cleanup wipes an entire drive

A developer asked the agent in Google Antigravity to clear a project cache. The agent ran a quiet recursive delete, but the path pointed at the root of the D: drive instead of the cache folder. The quiet flag skipped the Recycle Bin, so the files were gone for good. The agent apologised at length. Google said it was investigating.

A delete aimed at a drive root should never run unattended. The path is the whole difference between a cleanup and a wipe.

26 Feb 2026 · Claude Code

terraform destroy takes out production and its backups

The founder of DataTalks.Club was moving a site to AWS and reused the Terraform setup of his production platform. A prompt you can approve in a hurry is not enough for commands like this. Make destroy impossible for the agent and run it yourself.

Apr 2026 · Cursor

One API call deletes a company database and its backups

The founder of PocketOS reported that a Cursor agent, working on a routine task in staging, hit a problem and decided to fix it by deleting a storage volume on the hosting platform. It used a broadly scoped API token it had found elsewhere in the project. The call took about nine seconds. The volume held the production database and its backups. The platform later helped restore the data after a long outage.

Deletes do not only come from rm. A single HTTP call with a found token can do it, so the guard has to read API calls too.
